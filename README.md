# Invitaciones Baby Shower

```bash
npm run dev
```

- Datos del evento (bebé, fecha, lugar, WhatsApp): `lib/evento.ts`
- Diseño: `components/Invitacion.tsx` y paleta en `app/globals.css`
- Un invitado = una carpeta: `app/(invitados)/<slug>/page.tsx` → URL `/<slug>`. Copia `app/(invitados)/ejemplo/page.tsx` como base.
